# 🌿 EcoRuta Palín

> Proyecto de **Emprendimiento de Negocios Tecnológicos** (8vo Semestre).  
> Solución digital orientada a la sostenibilidad, turismo ecológico y gestión ambiental comunitaria en el municipio de Palín, Escuintla.

---

## 🚀 Acerca del Proyecto

**EcoRuta Palín** es una iniciativa tecnológica concebida para conectar a los ciudadanos, visitantes y comercios locales con prácticas sostenibles, rutas verdes y puntos de interés ecológico y cultural en Palín.

### 🌟 Objetivos Principales
- **Promoción del Ecoturismo:** Mapeo interactivo de senderos, atractivos naturales y patrimonio cultural.
- **Conciencia Ambiental:** Información sobre centros de acopio, puntos de reciclaje y gestión de residuos.
- **Economía Circular Local:** Visibilidad para emprendedores locales y negocios sostenibles.
